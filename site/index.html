ใน KCP ทั้ง 13 แถวนี้รวมเหลือ 4 กลุ่มเรียน แต่ละกลุ่มแสดงเพียงครั้งเดียว

ทุกอย่างที่ใช้ในการจัดตารางเรียน อยู่ในแผงเดียว

ค้นหาได้สามแบบ เหมือนหน้าลงทะเบียน

ค้นหาตามหลักสูตรและชั้นปี รหัสวิชา หรือหมวดวิชา ผลค้นหาแสดงเป็นการ์ดรายวิชาที่ย่อไว้หนึ่งบรรทัด เปิดดูกลุ่มเรียน ที่นั่งว่าง เงื่อนไขการลงทะเบียน และวันสอบได้ในที่เดียว และกรองตามวัน หน่วยกิต หรือซ่อนกลุ่มเรียนที่เต็มได้ทันที

ลากลงตาราง แล้วเห็นทันทีว่าชนหรือไม่

เมื่อเริ่มลากกลุ่มเรียน ตารางจะแสดงตำแหน่งของทุกคาบเรียนล่วงหน้า กรอบสีเขียวคือวางได้ ลายเส้นสีแดงคือชนกับวิชาที่อยู่ในตาราง พร้อมชื่อวิชาและเวลาที่ชน วางทับวิชาที่ชนเพื่อสลับสองวิชาได้ ถ้าวางไม่ได้ KCP จะเสนอกลุ่มเรียนอื่นของวิชาเดียวกันที่ลงได้ กลุ่มเรียนที่จับคู่ทฤษฎีกับปฏิบัติจะถูกเพิ่มและนำออกพร้อมกันเสมอ

ตรวจวันสอบให้ด้วย ไม่ใช่แค่เวลาเรียน

สองวิชาที่เรียนคนละวันอาจสอบกลางภาคเวลาเดียวกัน KCP เทียบช่วงสอบกลางภาคและปลายภาคของทุกวิชาในตาราง และไม่ให้เพิ่มกลุ่มเรียนที่สอบชนกัน มุมมองสรุปเรียงตารางสอบทั้งภาคตามวันที่ พร้อมชั่วโมงเรียนต่อสัปดาห์และวันว่าง

ใช้ได้ทั้งจอกว้าง หน้าต่างแคบ และแล็ปท็อปจอสัมผัส

KCP ทำงานบนเบราว์เซอร์คอมพิวเตอร์ที่รองรับส่วนขยาย ได้ทุกขนาดหน้าต่าง บนจอกว้าง รายวิชาอยู่ข้างตาราง ในหน้าต่างขนาดกลาง รายวิชาเปิดเป็นแผ่นด้านข้าง และในหน้าต่างที่แคบกว่า 640 px ตัววางแผนจะแสดงทีละส่วนพร้อมแถบนำทางด้านล่าง ตารางแสดงทีละวัน และแตะค้างเพื่อลากกลุ่มเรียนบนแล็ปท็อปจอสัมผัส

KCP ยังใช้บนโทรศัพท์ไม่ได้ ดูเหตุผลได้ในคำถามที่พบบ่อย

แชร์ตารางเป็นรูปภาพที่พร้อมส่ง

โหมดดูตัวอย่างจัดตารางเป็นภาพโปสเตอร์ เลือกแม่แบบสำหรับแชร์ 16:9 ภาพพื้นหลังโทรศัพท์ ภาพพื้นหลังแท็บเล็ต หรือพิมพ์ A4 แล้วดาวน์โหลด คัดลอกรูปภาพ หรือคัดลอกเป็นข้อความสำหรับแอปแชท ภาพที่ได้มีขนาดเท่ากันทุกครั้งไม่ว่าจะส่งออกจากหน้าจอขนาดใด และเลือกแสดงตารางสอบใต้ตารางเรียนได้

แม่แบบ แชร์ 16:9 ภาพพื้นหลังโทรศัพท์แนวตั้งและแนวนอน ภาพพื้นหลังแท็บเล็ตแนวตั้งและแนวนอน และพิมพ์ A4

เก็บได้หลายตาราง และตรวจกับข้อมูลล่าสุดเมื่อเปิด

สร้างตารางได้หลายตารางต่อภาคการศึกษา ตั้งชื่อ ทำสำเนา และส่งออกเป็นไฟล์ได้ เมื่อเปิดตาราง KCP จะตรวจกลุ่มเรียนในตารางกับข้อมูลล่าสุด ถ้าเวลา ห้อง หรือวันสอบเปลี่ยน หรือกลุ่มเรียนไม่อยู่ในระบบแล้ว จะแสดงค่าเดิมและค่าใหม่ให้ตรวจ โดยไม่ลบสิ่งใดออกเอง

ข้อมูลอยู่ในเบราว์เซอร์ของคุณ และเข้าถึงเว็บไซต์แบบอ่านอย่างเดียว

KCP ไม่มีบัญชีผู้ใช้ ไม่มีเซิร์ฟเวอร์ และไม่เก็บสถิติการใช้งาน ส่วนขยายอ่านเฉพาะข้อมูลรายวิชาสาธารณะที่หน้าลงทะเบียนใช้อยู่แล้ว ไม่แตะการเข้าสู่ระบบ ไม่กรอกหรือส่งแบบฟอร์ม และไม่ลงทะเบียนแทนคุณ

ความสามารถอื่นที่ช่วยตัดสินใจ

แนะนำตาราง
หลังค้นหาตามหลักสูตร KCP เสนอตารางที่ไม่ชนกันได้สูงสุดสามแบบจากวิชาบังคับคณะ วิชาบังคับหลักสูตร และวิชาเลือกหลักสูตร ไม่รวมวิชา GenEd และวิชาเลือกเสรี เลือกเน้นเช้า เน้นบ่าย เรียนน้อยวัน และรูปแบบอื่นได้
เปรียบเทียบกลุ่มเรียน
เทียบทุกกลุ่มเรียนของวิชาหนึ่งเคียงกัน ทั้งเวลา ผู้สอน ที่นั่ง วันสอบ และเงื่อนไข แล้วเพิ่มลงตารางจากหน้าต่างนั้นได้
ที่นั่งและผู้ลงทะเบียนล่วงหน้า
ทุกกลุ่มเรียนแสดงที่นั่งว่างจากจำนวนรับ และแจ้งเมื่อผู้ลงทะเบียนล่วงหน้ามากกว่าที่นั่ง
เปิดได้หลายทาง
เปิดตัววางแผนจากปุ่ม Planner มุมขวาล่าง ไอคอนส่วนขยาย หรือแป้นลัด Alt+Shift+P
สองภาษา

คำถามที่พบบ่อย

KCP คืออะไร

KCP หรือ Course Planner for KMITL เป็นส่วนขยายเบราว์เซอร์สำหรับวางแผนตารางเรียนก่อนลงทะเบียน โดยใช้ข้อมูลรายวิชาที่เปิดสอนจากเว็บไซต์ลงทะเบียนของ สจล.

KCP เป็นระบบของ สจล. หรือไม่

KCP ไม่ใช่ระบบของ สจล. แต่เป็นเครื่องมืออิสระที่นักศึกษาพัฒนา ไม่มีความเกี่ยวข้อง ไม่ได้รับการสนับสนุน และไม่ได้รับการรับรองจากสถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง

KCP ลงทะเบียนเรียนให้ได้ไหม

KCP ไม่ลงทะเบียนแทนคุณ ใช้สำหรับวางแผนก่อนลงทะเบียนเท่านั้น การลงทะเบียนจริงยังทำบนเว็บไซต์ลงทะเบียนของสถาบันตามปกติ ส่วนขยายไม่กรอกแบบฟอร์มและไม่ส่งคำขอใดแทนคุณ

ข้อมูลของฉันถูกส่งไปที่ใดหรือไม่

ข้อมูลไม่ถูกส่งออกจากเครื่อง ตารางที่บันทึกอยู่ในพื้นที่จัดเก็บของเบราว์เซอร์บนเครื่องนี้ ไม่มีบัญชีผู้ใช้ ไม่มีเซิร์ฟเวอร์ และไม่มีการติดตามการใช้งาน การนำส่วนขยายออกจะลบข้อมูลเหล่านี้ด้วย

ใช้กับเบราว์เซอร์ใดได้บ้าง

Chrome, Microsoft Edge, Brave, Opera และเบราว์เซอร์ Chromium อื่นติดตั้งจาก Chrome Web Store ส่วน Firefox ติดตั้งจาก Firefox Add-ons ทั้งหมดใช้บนคอมพิวเตอร์ บน Opera อาจต้องติดตั้งตัวช่วยของ Opera สำหรับส่วนขยายจาก Chrome Web Store ก่อน

ใช้บนโทรศัพท์ได้ไหม

ขณะนี้ยังใช้บนโทรศัพท์ไม่ได้ เพราะ Chrome บนโทรศัพท์ไม่รองรับส่วนขยาย และยังไม่ได้ยืนยันการรองรับ Firefox สำหรับ Android ตัววางแผนจัดหน้าจอสำหรับหน้าต่างแคบและจอสัมผัสไว้แล้ว และเวอร์ชันเว็บที่อยู่ระหว่างพัฒนามีแผนให้ใช้ได้โดยไม่ต้องติดตั้งส่วนขยาย

เวอร์ชันเว็บจะเปิดเมื่อไร

ยังไม่มีกำหนด เมื่อเปิดใช้ ปุ่มใช้งานบนเว็บในหน้านี้จะเปลี่ยนเป็นลิงก์ที่ใช้ได้ ระหว่างนี้ใช้ส่วนขยายบน Chrome หรือ Firefox ได้

ข้อมูลรายวิชาเป็นปัจจุบันแค่ไหน

KCP แสดงข้อมูลเดียวกับที่เว็บไซต์ลงทะเบียนส่งมา และตรวจรูปแบบข้อมูลทุกครั้งก่อนแสดง ผลค้นหาบอกเวลาที่ดึงข้อมูล และตารางที่บันทึกไว้จะถูกตรวจกับข้อมูลล่าสุดเมื่อเปิด ก่อนลงทะเบียนจริงควรตรวจกับเว็บไซต์ลงทะเบียนอีกครั้ง

ย้ายตารางไปเครื่องอื่นได้ไหม

ได้ ส่งออกตารางเป็นไฟล์ JSON จากเมนูตาราง แล้วนำเข้าบนเครื่องอื่น ตารางที่นำเข้าจะถูกตรวจกับข้อมูลล่าสุดเมื่อเปิดครั้งแรก

KCP มีค่าใช้จ่ายไหม

ไม่มีค่าใช้จ่าย KCP ใช้ได้ฟรีและเป็นโอเพนซอร์สภายใต้สัญญาอนุญาต MIT

KCP: Course Planner for KMITL เป็นเครื่องมืออิสระที่นักศึกษาพัฒนา ไม่มีความเกี่ยวข้อง ไม่ได้รับการสนับสนุน และไม่ได้รับการรับรองจากสถาบันเทคโนโลยีพระจอมเกล้าเจ้าคุณทหารลาดกระบัง (สจล.) ชื่อ สจล. และ KMITL ใช้เพื่อระบุเว็บไซต์ที่เครื่องมือนี้ทำงานด้วยเท่านั้น
