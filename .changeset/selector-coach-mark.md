The registration search page now dims and points at the Planner button each time you arrive on it, so the planner is easy to find. Choose Maybe later to hide it for this visit, or Not again today to keep it away until tomorrow. The Planner button stays usable while the prompt shows. After either choice a ring marks the Planner button for a moment, so you can find it later.
